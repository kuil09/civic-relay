# ADR 0003: Official-source-first, runtime verification

- Status: accepted
- Date: 2026-08-27
- Issues: #7, #8, #9, #14, #22

## Decision

공식 법령, 국회, 정부, 지자체 자료를 우선한다. 저장소에 현직자·연락처를 최신 상수로 저장하지 않는다. 수신자 확정과 발송 직전에 공식 출처로 재검증한다.

공식 API가 없거나 실패하면 웹 원문을 확인하고 출처·확인 시각·실패 사유를 기록한다. 검색 결과 요약만으로 법적 사실을 확정하지 않는다.

## Consequences

예제의 수신자 스냅샷은 항상 발송 불가 상태다. 네트워크가 없는 환경은 조사 계획과 초안까지만 진행한다.
