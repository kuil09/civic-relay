# Phase 4 Design Boundary

이 문서는 #23의 구현 경계를 정의한다. Phase 4는 #21 종단간 사례와 실제 사용자 피드백 전에는 코어에 결합하지 않는다.

## 협업 편집

향후 역할 후보:

- 사례 작성자
- 근거 검토자
- 정책안 편집자
- 수신자 검증자
- 발송 승인자
- 공개본 관리자

개인 의견, 단체 공식안, 공동 서명은 별도 엔터티여야 하며 이름을 자동으로 합치지 않는다.

## 공개 사례 라이브러리

- `redact`를 통과한 공개본만 게시
- 수신자 정보는 기본 만료·발송 불가
- 원 사례의 사실을 새 사례의 사실로 복사하지 않음
- 재사용 대상은 문제 프레임, 조사 질문, 대안·반론 패턴

## 관할 어댑터

공통 코어 밖에서 다음을 제공한다.

- 법적 계층
- 의회·위원회 구조
- 행정부·지방정부 구조
- 공식 데이터 소스
- 직책·날짜·연락 채널 정규화
- 현재성 유효기간과 검증 절차

두 번째 관할을 구현하기 전까지 인터페이스를 과도하게 일반화하지 않는다.
